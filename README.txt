ATCM 2335 — WEEK 10 STARTER
JavaScript as Writing and Behavior

Open index.html in a browser or use Live Server in VS Code.

Try:
1. Change the five words.
2. Change the random ranges.
3. Add a second event such as mouseover.
4. Change background color, opacity, scale, position, or rotation.
5. Make the behavior match the meaning of the poem.

The goal is not to add interaction just because you can.
The behavior should contribute to the poem.
